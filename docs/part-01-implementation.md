# الجزء 01 — النواة وقاعدة البيانات وسجل المشاريع

## الحالة

**اكتمل نطاق طبقة البيانات وسجل المشاريع للجزء 01، واجتاز بوابات الاختبار المذكورة أدناه.** يمكن الآن استعادة جلسات Sandbox الحتمية من آخر checkpoint، كما اختُبر clone حقيقي لمستودع GitHub. هذا لا يعني اكتمال المنتج النهائي أو إطلاقه بأمان: استعادة سياق وكيل مزود نموذج بالضبط وتشغيله على مشروع مستورد يتطلبان طبقات runtime والأمان التالية؛ لا تكشف API للشبكات العامة قبل إنجاز الجزء 02.

## ما أُنجز

- قاعدة SQLite محلية عبر `@libsql/client` وDrizzle، مع تفعيل WAL وforeign keys وbusy timeout.
- ترحيل ابتدائي مُرقّم في `server/db/migrations/0001_initial.ts`، وسجل `schema_migrations`.
- مخطط دائم للمشاريع والجلسات والوكلاء والرسائل واستدعاءات الأدوات ونقاط الحفظ والفروع وعمليات الدمج وسجل الأحداث والاستخدام.
- سجل أحداث append-only، مع تسلسل لكل stream، وإعادة قراءة من رقم تسلسلي، وحفظ أحداث AG-UI (باستثناء snapshot المتكرر) مع سجل JSONL كنسخة تصدير/توافق. كُتّاب SQLite المحليون متسلسلون لتفادي تصادم معاملات العملية الواحدة.
- حفظ snapshots الجلسات ومعاملاتها في transaction: صف الجلسة، الوكلاء، الرسائل الأولية/النشاط، نقاط الحفظ، والفروع. استدعاءات الأدوات تسجل في جدولها، ويُسجّل استهلاك input/output tokens عند توفره من مزود النموذج. تُحسب التكلفة فقط إذا ضبط المشغّل أسعاراً صريحة لكل نموذج في `FORKSTREAM_MODEL_PRICING_JSON` (دولار لكل مليون token)؛ وإلا تُوسم القيمة بأنها غير معروفة، ولا نفسّر الصفر على أنه تكلفة مجانية.
- يتم flush للحالة عند نقاط البناء/checkpoint وعند انتهاء المهمة. عند تشغيل الخدمة، توسم الجلسات التي كانت `running` أو `paused` أو `idle` بحالة `interrupted`، ويظل آخر snapshot والسجل متاحين عبر API. هذا **استرجاع للسجل والحالة المحفوظة** وليس استئنافاً تلقائياً لتنفيذ الوكيل.
- سجل مشاريع دائم مع تسجيل مسار محلي حقيقي، canonical path، اكتشاف Git والفرع واللغات ومديري الحزم وأوامر manifests. إعادة تسجيل المسار نفسه idempotent.
- استنساخ HTTPS محصور حالياً في `github.com`، بلا username/password، وبـ `execFile` وتمرير معاملات منفصلة لا shell interpolation.
- API: `GET /api/projects`, `GET /api/projects/:id`, `POST /api/projects` (new/local/clone), `POST /api/projects/:id/open`, `GET /api/sessions/history`، `GET /api/sessions/:id/transcript`، استرجاع snapshot عبر `GET /api/sessions/:id`، و`POST /api/sessions/:id/recover` لاستئناف Sandbox مدعوم.
- عيّنة تحقق: `npm run test:part01`.

## حدود واعتماديات معروفة

1. أحداث AG-UI تُسجل وتُقرأ من قاعدة البيانات، لكن لم يُنفّذ بعد reducer يعيد بناء حالة الجلسة الحية كاملة من نقطة snapshot ثم الأحداث؛ replay المتاح حالياً هو سجل أحداث/ترانسكريبت، لا استعادة حتمية لكل الذاكرة.
2. استئناف Sandbox الحتمي مدعوم عبر إرفاق مستودع الجلسة والتحقق من مساره ومواصلة الخطوات غير المكتملة دون تكرار checkpoint المنجز. استئناف جلسات LLM/OpenCode ليس بعد: يتطلب حفظ/استعادة سياق مزود النموذج وهوية العمليات وسياسة تحقق من الآثار الجانبية. الفروع المتوازية غير المنتهية ترفض الاستعادة الآلية حتى لا يحدث تلف.
3. سجل المشاريع لا يعني أن الوكيل بدأ بعد بتعديل هذا المشروع. تشغيله يتطلب إكمال حدود الأمان والعزل وسياسة المشروع في الأجزاء اللاحقة.
4. SQLite هنا قاعدة محلية بعملية كاتبة واحدة؛ تعدد نسخ الخادم/كتّاب مستقلين يحتاج تحققاً إضافياً أو انتقالاً إلى PostgreSQL، ولا يُعلن دعمه الآن.
5. snapshots قد تتضمن محتوى مشروع ورسائل. لا تنشر الخدمة على شبكة غير موثوقة قبل الجزء 02 (مصادقة، سياسات، أسرار، عزل) ومراجعة تخزين البيانات والاحتفاظ بها.
6. قيود clone الحالية محافظة عمداً، ودعم GitLab/SSH وبيئات خاصة يُضاف بعد نموذج تهديد وحدود شبكة موثقة.

## بوابات تحقق

- `npm run typecheck`
- `npm run test:part01` (يتضمن استعادة Sandbox من checkpoint جزئي)
- `npm run test:clone:integration` (اختبار شبكة حقيقي اختياري، يستنسخ `octocat/Hello-World` إلى مجلد مؤقت ثم ينظفه)
- `npm run test:engine`
- `npm run build`

اختبارات الجزء 01 تتحقق من إنشاء وإعادة فتح قاعدة البيانات، حفظ المشاريع والجلسات والأحداث عبر restart، ترتيب أحداث متزامنة داخل العملية، اكتشاف مستودع Git، idempotency، واختبار رفض host غير مسموح للـ clone.

## المتغيرات

- `FORKSTREAM_DB_PATH` — مسار قاعدة البيانات؛ الافتراضي `data/forkstream.sqlite`.
- `FORKSTREAM_PROJECTS_ROOT` — مجلد المشاريع الجديدة/المستنسخة؛ الافتراضي `workspaces/projects`.
- `FORKSTREAM_MODEL_PRICING_JSON` — اختياري؛ كائن JSON بمفاتيح `provider/model` أو `model` وقيم `{ "inputUsdPerMillion": number, "outputUsdPerMillion": number }`. لا توجد أسعار افتراضية مخترعة.

المجلدات المحلية لقاعدة البيانات ونسخ المشاريع مستثناة من Git عبر `.gitignore`.
